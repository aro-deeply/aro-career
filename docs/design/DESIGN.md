# ARO DESIGN.md — 평가자의 펜 자국

ARO 웹 화면(랜딩 `launch/`, 진단·경험 정리 `src/diagnosis/`)을 만들거나 고칠 때 따르는 규칙이다.
AI에게 화면 작업을 맡길 때는 "예쁘게"가 아니라 이 파일을 통째로 준다.

## 1. 한 줄 콘셉트

**지원서 위에 평가자가 펜으로 남긴 메모.**
ARO가 하는 일(평가자 시선으로 읽고, 빈칸을 질문으로 짚는 것)을 설명하지 않고 화면으로 보여 준다.
페이지는 홍보물이 아니라 한 사람이 쓴 검토 메모처럼 읽혀야 한다.

## 2. 쓰지 않는 것 (AI가 만든 랜딩의 흔한 흔적)

| 금지 | 대신 |
|---|---|
| 가운데 정렬 첫 화면 | 왼쪽 정렬, 문서처럼 위에서 아래로 읽힘 |
| 점이 달린 알약 배지("● 새 기능 →") | 문서 머리말 같은 작은 글 한 줄 |
| 제목 속 단어 하나만 색칠(`<em>`) | 제목은 한 색. 강조는 펜 자국(밑줄·동그라미)으로만 |
| 같은 모양 카드 3개 나열 | 목록·표·문단. 카드가 꼭 필요하면 종이 한 장(.sheet)만 |
| "일반 AI vs 우리" 비교표 | 실제 예시 문장에 펜 메모를 단 장면 |
| 빛나는 그라데이션 상자, 글로우, 네온 | 평평한 종이와 선 |
| 섹션마다 같은 리듬(작은 파란 소제목 → 큰 제목 → 카드) | 문서 번호(01, 02…)와 여백 메모 칸 |
| 알약 모양 버튼 여러 개 | 검은 사각 버튼 하나 + 밑줄 글자 링크 |
| 이모지 아이콘 | 없음 (카카오톡 버튼의 💬만 예외) |
| 내용 없는 수식어(혁신적인, 완벽한, 최고의) | 사실과 행동 |

## 3. 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--desk` | `#F4F4F1` | 페이지 바탕(책상) |
| `--paper` | `#FFFFFF` | 종이(.sheet) |
| `--ink` | `#121214` | 본문·제목·버튼 |
| `--ink-soft` | `#5E5E64` | 보조 글 |
| `--rule` | `#E3E3DF` | 구분선 |
| `--pen` | `#C2392B` | 평가자의 펜 자국과 여백 메모에만 |
| `--pen-soft` | `rgba(194,57,43,.08)` | 펜 메모 바탕(아주 옅게) |

- 펜 색은 **표시**에만 쓴다. 버튼·링크·배경에 쓰지 않는다.
- 진단·경험 정리 도구 화면은 조작 요소가 많아 파란 포인트(`#2F4DB3`)를 유지한다. 랜딩은 파란색을 쓰지 않는다.
- 그라데이션 금지(테스트로 막혀 있음).

## 4. 글자

- 글꼴은 SUIT 하나(`/fonts/SUIT-Variable.woff2`). 명조체 금지.
- 크기는 다섯 단계 변수만: `--t-display`, `--t-title`, `--t-lead`, `--t-body`, `--t-caption`. 새 크기를 만들지 않는다.
- 제목도 과하게 크지 않게(데스크톱 최대 약 52px). 굵기는 500·700 두 가지.
- 한 줄 40자 이내(테스트로 막혀 있음). 길면 `<br>`로 끊는다.

## 5. 배치

- 데스크톱: 본문 칸(최대 640px) + 오른쪽 여백 메모 칸(220px). 모두 왼쪽 정렬.
- 섹션은 얇은 선으로 나누고, 여백 칸 위쪽에 문서 번호(01, 02…)를 단다.
- 휴대폰: 한 칸. 여백 메모는 해당 줄 바로 아래로 내려온다(↳).
- 모서리: 종이 4px, 버튼 4px. 둥근 알약 모양은 쓰지 않는다.
- 그림자: 종이에만, 아주 옅게 한 겹.

## 6. 움직임

- 펜 자국이 화면에 들어올 때 **그려진다**(밑줄이 왼쪽에서 오른쪽으로, 동그라미가 한 바퀴). 0.6~0.9초, 한 번만.
- 여백 메모는 펜 자국 다음에 0.2초 늦게 나타난다.
- 그 밖의 등장 효과는 옅은 페이드 하나만. 반복·깜빡임·숫자 카운트업 금지.
- `prefers-reduced-motion`이면 전부 바로 보이게 한다.

## 7. 말투

- 랜딩: "~합니다" 존댓말. 짧은 문장. 주어는 평가자 또는 ARO.
- 도구 화면: "~해요" 존댓말.
- 예시는 직장인 사례만. 예시·가상 표시는 섹션 끝 작은 각주로(배지 금지).
- 근거 없는 수치·실적·가격 금지. 확인된 사실만: 기업 HR 약 16년, 채용·평가·교육.

## 8. 확인 순서

1. 첫 화면이 가운데 정렬·배지·색칠 단어 없이 시작하는가
2. 카드가 반복되지 않는가, 비교표가 없는가
3. 펜 색이 표시에만 쓰였는가
4. `npm test`의 랜딩 검사(40자·글자 크기·글꼴·외부 링크·사실 표기)가 통과하는가
5. 390px에서 가로 넘침이 없는가
